# Funniest One-Line Out-of-Office Reply

A one-line out-of-office auto-reply (86 characters), for the make.fun bounty
[Funniest One-Line Out-of-Office Reply](https://make.fun/bounty/u-hamsyh-funniest-one-line-out-of-office-reply-5490c1c8).

> I'm out of office until Monday. If this is urgent, it isn't — I checked before I left.

`main.ts` writes that single line to `/output/entry.txt`. The joke is a
reversal of the usual away message: instead of promising urgent mail will
be handled, the sender has already audited the urgency and dismissed it —
deadpan, in one breath, with the return date keeping it a real auto-reply
someone would actually switch on.
